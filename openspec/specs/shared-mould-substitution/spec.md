# SKU 无模具可用时的共用模具联动置换规则

## Purpose

硫化排程完成续作、换活字块和正常新增排产后，若物料 A 仍有待排量且当前没有任何空闲有效模具，
但 A 与物料 B 存在精确的共用模具关系，并且该共用模具正在 B 的真实续作机台上使用，则允许执行
一次 A/B 联动置换：

1. B 在 A 接管前从原续作机台下机并释放原模具；
2. A 原机台原模具无缝接管，不换模、不换活字块、不执行首检；
3. B 携带除转交模具外的剩余空闲有效模具，复用现有新增选机和正规换模主链迁移到新机台；
4. 仅当 A 接管、B 剩余模具、B 新机台、B 合法换模时间和精确尾量全部成立时，才原子提交。

核心原则：**先确保物料 B 能携带剩余模具成功迁移，再允许物料 A 接管原机台。**

## Requirements

### Requirement: 在 S4.5.1 先执行共用模具联动置换

系统 MUST 在 S4.5 新增排产完成后、S4.6 结果校验与保存前执行本规则。

S4.5.1 的固定执行顺序 MUST 为：

1. 对全部仍有正待排量的 SKU 执行共用模具联动置换；
2. 对置换后仍未排的特殊材料 SKU 执行原特殊材料机台置换兜底；
3. 同步结构最小保机运行态；
4. 进入 S4.6。

系统 MUST 在 S4.5 写入任何新增结果前冻结允许置换的续作结果身份。冻结结果 MUST 同时满足：

1. 排程类型为续作；
2. 机台存在排程开始时的初始在机快照；
3. 结果物料与初始在机物料一致。

新增排产、换活字块、特殊材料置换结果以及其他来源机台 MUST NOT 参与本规则。

#### Scenario: 非续作机台不得参与置换

- **GIVEN** 某机台由 S4.5 新增排产或其他非续作来源占用
- **WHEN** 系统构建共用模具置换候选
- **THEN** 该机台不得被截断、迁移或交给 A

### Requirement: A 必须同时满足三个硬门槛

系统 MUST 仅在物料 A 同时满足以下条件时尝试置换：

1. 以“物料编码+产品状态”为复合键仍有正待排量；
2. 在目标接管业务日刷新模具到货和状态后，没有其他空闲有效模具；
3. A 与 B 对原机台当前实际绑定的每个精确模具号均存在有效共用模具关系；
4. 这些精确共用模具当前正在 B 的冻结续作机台上使用。

“没有其他空闲有效模具” MUST 排除已占用、已预占、禁用、不可用和未到货模具。
系统 MUST NOT 使用同模套、同模壳、同规格或相邻模具号推断共用关系。

只要 A 存在一个其他空闲有效模具，系统 MUST NOT 抢占 B 的续作机台，并保持原新增排产语义。

#### Scenario: A 存在其他空闲模具

- **WHEN** A 在目标业务日存在至少一个空闲有效模具
- **THEN** 系统不得执行共用模具联动置换
- **AND** A 保持原未排或原新增排产处理结果

#### Scenario: 共用模具未在 B 的续作机台使用

- **WHEN** A 与 B 存在共用模具关系
- **BUT** 共用模具当前未绑定在 B 的冻结续作机台
- **THEN** 该机台不得成为置换候选

### Requirement: 单控机台按完整物理机台置换

普通机台 MUST 继承其当前完整模具集合。

单控 L/R 机台 MUST 按完整物理机台处理，并同时满足：

1. L/R 两侧均属于同一物料 B；
2. L/R 两侧当前实际绑定模具均对 A、B 有效；
3. A 同时接管 L/R 两侧及其全部模具；
4. B 的迁移结果由一个新的完整物理机台承接。

系统 MUST NOT 只置换单控机台的一侧。

### Requirement: B 必须存在除转交模具外的剩余空闲有效模具

系统 MUST 在预演 B 迁移前重新解析 B 的剩余模具。剩余模具 MUST 排除：

1. 已被任意机台占用的模具；
2. 已被当前排程候选预占的模具；
3. 禁用、台账不可用或目标业务日尚未到货的模具；
4. 本次转交给 A 的全部模具；
5. 候选新机台当前绑定、仅可在换模时释放的旧模具。

B 迁移预演 MUST 只能从上述过滤后的剩余模具集合中分配，不得把候选新机台的旧模具当作 B
预先具备的剩余模具。

#### Scenario: B 有剩余模具且可重新选机

- **GIVEN** B 除转交模具外存在空闲有效模具
- **AND** B 能通过现有主链找到合法新机台和换模时间
- **WHEN** 系统完成 A/B 全量预演
- **THEN** 系统允许提交联动置换

#### Scenario: B 无剩余模具

- **GIVEN** B 除转交模具外没有空闲有效模具
- **WHEN** 系统评估当前续作候选
- **THEN** 当前候选置换被禁止
- **AND** 系统继续尝试其他续作候选
- **AND** 全部失败时 A 按现有逻辑保留未排结果

### Requirement: A 的最早正计划日决定接管目标

系统 MUST 从排程窗口首日开始逐日扫描 A 的月计划日计划量，选择最早大于 0 的日期。

窗口内没有正计划量时，系统 MUST 复用现有提前生产准入逻辑，在允许提前生产范围内查找首个
正计划来源日。未来来源日只作为提前生产来源日期保留，实际接管仍 MUST 通过现有 T～T+2
日驱动和提前生产规则确定，系统 MUST NOT 绕过提前生产阈值。

B 的下机时间 MUST 不晚于 A 的实际开产时间。

#### Scenario: T+1 首次存在正计划量

- **GIVEN** A 在 T 日计划量为 0、T+1 日计划量大于 0
- **WHEN** 系统解析置换目标日期
- **THEN** 目标日期为 T+1
- **AND** B 在 A 的 T+1 实际开产前完成下机

### Requirement: B 的截断尾量必须完整且守恒

系统 MUST 复用续作局部截断口径，在 B 下机时间：

1. 保留下机前已经完成的完整硫化循环；
2. 截断下机后的班次量和班次内尾量；
3. 释放被截断量对应的原机台班次产能；
4. 刷新续作结果的班次量、结束时间和已排机台登记；
5. 将截断量恢复到 B 的实际生产余量、对应日计划账本和满班补齐账本。

B 的迁移副本 MUST 使用续作增机来源，且一个新物理机台的最终正计划量 MUST 严格等于截断尾量，
不得少排、超排或分散到多个物理机台。

### Requirement: A 原机台原模具无缝接管

A 接管 MUST 复用现有新增规格机台产能、停机、清洗、日驱动、提前生产和班次分配逻辑，但结果必须：

1. `scheduleType=02`；
2. `isChangeMould=0`；
3. `isTypeBlock=0`；
4. 不分配首检资源，不扣减首检产能；
5. 不占用换模次数和早中班换模均衡资源；
6. 不生成模具交替计划或换模开始时间；
7. 使用 B 原机台当前实际绑定的完整模具集合。

### Requirement: B 迁移必须复用现有选机和正规换模主链

A 形成正计划量后，系统 MUST 立即以恢复的精确尾量构造 B 的续作增机副本，并重新执行现有
新增规格选机主链。

B 迁移 MUST 继续遵守：

1. 现有候选机台硬过滤和排序；
2. 定点、单控、模具适配和机台模数；
3. 机台真实班次产能和日标准量；
4. 设备停机、清洗、精度保养和胶囊预热；
5. 正规换模时长和首检；
6. 每日换模总次数不超过 15 次；
7. 早班 8 次、中班 7 次参考均衡；
8. 晚班和 20:00 后禁止换模；
9. 目标量、日计划量、胎胚库存和收尾上限。

B 的新机台换模时间和重新开产时间 MUST 均不早于 B 的原机台下机时间。
当前时间不可换模时，原换模主链 MUST 顺延到最近允许班次；窗口内无法形成合法结果时当前候选失败。

#### Scenario: B 下机落在晚班禁换模时间

- **GIVEN** B 在 20:00 后完成原机台下机
- **AND** 次日早班存在合法换模资源
- **WHEN** B 重新选机
- **THEN** 换模顺延到次日早班或后续合法班次
- **AND** A/B 联动时间轴保持合法

#### Scenario: 当日换模次数达到上限

- **GIVEN** B 可选机台所在日期已经达到每日换模总次数上限
- **WHEN** B 重新选机
- **THEN** 原换模主链禁止该时点换模或顺延到下一合法日期
- **AND** 窗口内无法形成合法结果时整体置换失败

### Requirement: 候选排序稳定且允许多组置换

系统 MUST 对每个基础候选完成全量预演后，按以下顺序选择可提交计划：

1. B 被截断并迁移的尾量升序；
2. B 最早合法重新开产时间升序；
3. 原物理机台编码升序。

A 仍有待排量时可继续处理下一组置换。已成功提交的前一组 MUST 保留；后一组失败只回滚后一组，
不得撤销先前成功组。

### Requirement: 使用协调器和通用快照保证原子提交

系统 MUST 使用独立协调器编排以下步骤：

1. 校验 A 的硬门槛；
2. 收集冻结续作候选并校验精确共用模具；
3. 校验 B 剩余模具；
4. 在通用快照作用域内预演 B 下机、A 接管和 B 迁移；
5. 恢复预演状态；
6. 锁定预演确认的 A 原机台原模具、B 新机台、B 剩余模具、时间轴和尾量；
7. 再次执行正式提交并逐项核对。

通用快照 MUST 覆盖至少：

- 排程结果及结果字段；
- 机台状态、机台班次产能和机台结果分配；
- 模具占用和机台模具绑定；
- A/B 生产余量和日计划账本；
- 胎胚库存消费和配额；
- 换模、首检、维保、胶囊和已排机台运行态；
- 未排结果；
- 换模计划、过程日志和置换记录；
- 提前生产运行视图。

预演或正式提交任一步失败时，系统 MUST 恢复候选前完整状态，不得只让 B 下机、只让 A 接管、
只消耗换模次数或只占用模具。

#### Scenario: B 有模具但无可用机台

- **GIVEN** A 可以在原机台产生正计划量
- **AND** B 存在剩余空闲有效模具
- **BUT** B 无法找到满足约束的新机台
- **WHEN** 系统正式提交联动计划
- **THEN** B 原续作结果、A 临时结果、模具、机台和全部账本恢复到提交前

### Requirement: 模具和机台时间不得重复占用

正式提交 MUST 再次执行精确模具分配校验。A 使用的转交模具与 B 新机台使用的剩余模具 MUST
互不相交。

任何精确模具在同一时间只允许绑定一个运行态机台。A/B 结果的机台、模具、下机、换模和开产时间
存在重叠冲突时，系统 MUST 拒绝提交并整体回滚。

MES 在机信息按机台回溯历史记录时，系统 MUST 继续按模具号比较各机台记录的新旧版本，并以
在线日期、更新时间、数据版本依次确定该模具的最新物理机台归属。旧机台记录中的模具已全部被
更新记录接管时，该旧记录 MUST NOT 再作为续作在机来源。

滚动排程继承历史结果及历史换模计划前，系统 MUST 使用相同的最新模具归属校验；历史模具已经
转移到其他物理机台时，冲突历史结果和对应换模计划 MUST NOT 继承。

S4.6 保存前 MUST 按结果实际模具号及所有有量班次时间再次校验跨物理机台并发占用。发现任一
重叠时 MUST 阻断整批持久化，不得仅保存其中一台机台的结果。

#### Scenario: 回溯记录中的模具已转移到新机台

- **GIVEN** 旧机台的回溯在机记录和新机台的更新在机记录包含同一精确模具号
- **AND** 新机台记录的在线日期、更新时间或数据版本更新
- **WHEN** 系统初始化续作运行态或执行滚动继承
- **THEN** 该模具仅归属新机台
- **AND** 旧机台不得生成或继承使用该模具的重叠结果及换模计划

### Requirement: 成功和失败信息可审计

每个成功组 MUST 生成运行态关联记录和排程过程日志，至少包含：

- A、B 物料编码及产品状态；
- 转交共用模具号和 B 迁移剩余模具号；
- 原物理机台、A 接管机台、B 新机台；
- B 下机时间；
- A 实际接管时间；
- B 换模时间和重新开产时间；
- B 精确迁移数量。

全部候选失败时 MUST 记录 A 和明确失败原因。预演期间产生的临时日志 MUST 随通用快照回滚，
不得写入最终结果。

B 因“除转交共用模具外无剩余空闲有效模具”在预演前被拒绝时，系统 MUST 额外生成候选级失败
过程日志，并记录 A、B、转交共用模具、原续作物理机台、B 下机目标时间、A 接管目标时间及明确
失败原因。由于该候选尚未进入选机和换模主链，新机台、B 换模时间及 B 重新开产时间 MUST 明确
标记为“未生成”，不得伪造部分置换已经执行。

## 完整性检查场景

专项测试和既有回归 MUST 覆盖：

1. B 有剩余模具且可重新选机，联动成功；
2. B 无剩余模具，当前候选被禁止；
3. B 有模具但无可用机台，整体回滚；
4. B 下机后命中晚班或 20:00 后禁换模，换模顺延；
5. 每日换模次数达到上限，禁止或顺延；
6. 非续作机台不得参与置换；
7. A 最早正日计划日期正确决定接管目标；
8. 模具、机台及排程时间不存在重复占用；
9. B 新物理机台精确承接全部尾量，不少排、不超排；
10. 原续作、新增排产和特殊材料兜底流程在无置换场景下保持原行为。
