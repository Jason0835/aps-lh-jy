# 新增排产胎胚最早可供硫化时间

**状态：已实现** | **实现日期：2026-07-28** | **适用链路：S4.5 新增排产**

## Purpose

规范 S4.5 新增排产按 SKU 结构名称读取胎胚最早可供硫化时间，并将其作为首检和正式生产的时间下限。换模等开产前准备动作继续使用既有时间轴；S4.4 换活字块、续作和未命中有效配置的新增 SKU 不受本能力影响。

## Requirements

### Requirement: 胎胚最早可供时间必须独立加载

系统 MUST 按 `FACTORY_CODE` 和排程窗口 `[T, T+3)` 查询 `T_CX_EMBRYO_LH_TIME`。时间配置加载 MUST 独立于胎胚实时库存和月计划胎胚编码，避免无胎胚编码时漏载结构时间。

系统 MUST 使用大小写敏感的 `STRUCTURE_NAME` 精确匹配。`IS_DELETE != 0`、空结构或空 `EARLIEST_LH_TIME` 的记录 MUST 被忽略；同结构多条有效记录 MUST 确定性取最小 `EARLIEST_LH_TIME`。

#### Scenario: 同结构重复配置

- **GIVEN** 同一结构在排程窗口内存在多条有效时间配置
- **WHEN** 系统初始化胎胚最早可供时间
- **THEN** 上下文 MUST 保存其中最早的 `EARLIEST_LH_TIME`
- **AND** 数据库返回顺序不得影响最终取值

#### Scenario: 无胎胚库存编码

- **GIVEN** 当前月计划没有有效胎胚编码
- **AND** 结构存在有效胎胚最早可供时间配置
- **WHEN** 系统加载基础数据
- **THEN** 结构时间配置 MUST 仍被加载

#### Scenario: 缺少有效配置

- **GIVEN** SKU 结构未命中有效配置
- **WHEN** S4.5 执行新增排产
- **THEN** 系统 MUST 完整保持原有换模、首检、开产和班次产能行为

### Requirement: 胎胚时间只限制首检和正式生产

系统 MUST 先按现有换模、维修、试制开产和增机日规则计算理论可开产时间，再将理论时间与胎胚最早可供时间取较晚值，并从该时刻重新执行既有停机和班次管控校正。

```text
实际生产开始时间 =
班次管控校正(max(现有规则最终理论可开产时间, 胎胚最早可供硫化时间))
```

系统 MUST NOT 因等待胎胚而推迟同一业务日内已经合法分配的换模准备动作，也 MUST NOT 新增跨业务日独立换模准备态。

#### Scenario: 换模提前完成后等待胎胚

- **GIVEN** 现有规则计算出的可开产时间为 09:00
- **AND** 胎胚最早可供时间为 10:00
- **WHEN** 换模已在 10:00 前完成
- **THEN** 换模时间 MUST 保持原结果
- **AND** 首检与正式生产 MUST 从不早于 10:00 的合法时刻开始

#### Scenario: 现有可开产时间更晚

- **GIVEN** 现有规则计算出的可开产时间为 11:30
- **AND** 胎胚最早可供时间为 10:00
- **WHEN** 系统计算实际生产开始时间
- **THEN** 实际生产 MUST 从不早于 11:30 的合法时刻开始

#### Scenario: 胎胚时间位于下一业务日

- **GIVEN** 当前业务日尚未到达胎胚最早可供时间
- **WHEN** S4.5 构建当前日候选
- **THEN** SKU MUST 延期至下一业务日
- **AND** 当前日 MUST NOT 占用机台、模具、换模或首检资源

### Requirement: 生产班次必须采用左闭右开边界

命中胎胚时间配置时，系统 MUST 使用 `[班次开始, 班次结束)` 定位首检和实际生产班次。时间等于班次开始时归当前班；时间等于班次结束时归下一班。

#### Scenario: 时间位于班次中间

- **GIVEN** 班次为 06:00～14:00
- **AND** 胎胚最早可供时间为 10:00
- **WHEN** 系统定位首检和生产班次
- **THEN** 首检和生产 MUST 归入该 06:00～14:00 班次
- **AND** 06:00～10:00 不得生成该 SKU 计划量

#### Scenario: 时间等于班次边界

- **WHEN** 胎胚最早可供时间等于班次开始时间
- **THEN** 该时间 MUST 归当前班次
- **WHEN** 胎胚最早可供时间等于班次结束时间
- **THEN** 该时间 MUST 归下一班次

### Requirement: 首班计划量必须按剩余有效时长折算

胎胚时间所在首班 MUST 从实际生产开始时间至该班结束时间计算有效生产时长，并继续扣除停机、清洗、保养和班次管控。系统 MUST 复用既有有效时间与产能折算方法，不得按完整班产生成计划量，不得产生负量或超过该班剩余产能。

首班有效生产窗口的开始时间 MUST 为“班次管控可生产开始时间”和“实际生产开始时间”中的较晚值；候选窗口产能、局部搜索估产和最终落班 MUST 使用同一个窗口秒数折算班产。

后续班次 MUST 继续使用现有完整班次排产和跨日在机延续逻辑，不得重复应用首次胎胚准入或首检。

#### Scenario: 首班为部分班次

- **GIVEN** 班次为 06:00～14:00
- **AND** 实际生产开始时间为 10:00
- **WHEN** 系统计算该班计划量
- **THEN** 计划量 MUST 仅按 10:00～14:00 的有效生产时长折算
- **AND** 计划量 MUST NOT 超过该班剩余物理产能
- **AND** 若班次管控仍从 06:00 开始，系统 MUST NOT 因此恢复使用 06:00～10:00 的产能

#### Scenario: 部分首班后连续生产

- **GIVEN** 首班已按剩余时长折算计划量
- **AND** SKU 仍有待排量
- **WHEN** 系统进入后续班次或下一业务日在机延续
- **THEN** 后续班次 MUST 按现有规则连续排产
- **AND** 系统 MUST NOT 重复换模、重复首检或重复应用胎胚准入

### Requirement: 首检必须归入实际开始生产班次

命中胎胚时间配置时，普通 SKU 首检条数 MUST 归入实际生产开始班次，并计入该部分班次总产能。若部分班次剩余产能小于完整首检条数，该班计划量 MUST 为 0，首检和正式生产 MUST 整体顺延至下一可生产班次。

普通 SKU 首检已写入结果后，同班正常生产上限 MUST 以“部分班次总产能 - 已写首检条数”计算；首检量和正常生产量相加 MUST NOT 超过该部分班次总产能。

试制 SKU MUST 继续执行“不生成首检条数、固定扣减 2 小时产能”的现有规则。若部分班次扣除固定 2 小时后不能形成正产量，首检和生产 MUST 整体顺延。

#### Scenario: 换模在前一班完成

- **GIVEN** 换模已在胎胚可供班次之前完成
- **WHEN** 胎胚开始可供
- **THEN** 首检 MUST 记录在实际开始生产班次
- **AND** 胎胚可供前班次 MUST NOT 记录该 SKU 首检条数

#### Scenario: 部分产能不足完整首检

- **GIVEN** 普通 SKU 首检需要 4 条
- **AND** 当前部分班次物理剩余产能小于 4 条
- **WHEN** 系统试算当前班次
- **THEN** 当前班次计划量 MUST 为 0
- **AND** 完整首检及正式生产 MUST 顺延至下一可生产班次
- **AND** 候选试算和局部搜索 MUST 同步将当前班及其之前班次可生产量归零，不得保留无首检的正常生产量

#### Scenario: 试制固定两小时

- **GIVEN** 试制 SKU 的实际生产开始时间位于首检班次中间
- **WHEN** 系统计算部分班次产能
- **THEN** 系统 MUST 从剩余有效产能继续扣除固定 2 小时
- **AND** 不得生成试制首检条数

### Requirement: 候选试算与最终落班必须使用同一时间下限

S4.5 候选窗口产能、局部搜索估产、首检预演和最终班次分配 MUST 使用同一胎胚时间下限及部分班次首检口径。系统 MUST NOT 使用胎胚可供前产能提高候选机台评分或目标量。

现有减量清单、收尾和前置未排硬规则 MUST 先完成判断；胎胚时间仅在进入选机、换模、首检和正式生产等资源分配前作为生产时间下限生效，不得改变既有硬规则的未排结果。

#### Scenario: 候选估产与结果一致

- **GIVEN** 胎胚时间裁掉首班一部分产能
- **WHEN** 系统执行候选产能试算、局部搜索和最终落班
- **THEN** 三条链路 MUST NOT 使用胎胚可供前产能
- **AND** 最终结果不得因候选高估而在提交阶段才失败

### Requirement: 窗口外时间必须形成明确未排原因

胎胚最早可供时间达到或晚于 T+2 业务日结束时间时，系统 MUST NOT 生成零数量结果或独立准备态，并 MUST 在窗口最终结算时写入“胎胚最早可供硫化时间超出排程窗口”。

#### Scenario: 胎胚时间超出三天窗口

- **GIVEN** 胎胚最早可供时间不在 T、T+1、T+2 任一可生产班次内
- **WHEN** 三天新增排产窗口结束
- **THEN** SKU MUST 以“胎胚最早可供硫化时间超出排程窗口”写入未排
- **AND** 不得残留机台、模具、换模、首检或计划量占用

### Requirement: 影响范围必须严格限定为 S4.5

本能力 MUST NOT 改变 S4.4 换活字块的首检和产能口径，也 MUST NOT 改变续作排产。现有按胎胚最早可供时间参与 SKU 排序的行为保留，但排序不等同于生产时间限制。

#### Scenario: S4.4 换活字块不受影响

- **GIVEN** SKU 通过 S4.4 换活字块排产
- **WHEN** 同结构存在胎胚时间配置
- **THEN** S4.4 MUST 继续执行原换活字块时间轴和首检规则
- **AND** 本规格的生产时间下限 MUST NOT 被应用

### Requirement: 成功提交后必须记录可对账日志

系统 MUST 在新增结果和账本成功提交后记录批次、排程日期、结构、SKU、机台、胎胚最早可供时间、理论可开产时间、实际生产开始时间、落地班次、有效生产秒数、首检量和折算计划量。失败候选 MUST NOT 写入成功应用过程日志。

#### Scenario: 成功结果记录时间链

- **WHEN** 命中胎胚时间配置的新增结果成功提交
- **THEN** 应用日志和过程日志 MUST 包含完整时间链及产能折算字段
- **AND** 日志口径 MUST 与最终落班结果一致
